## 契约与边界

- 保留唯一文档 owner `BoardStore`。一次用户编辑操作对应一次历史；选择、镜头、临时指针和编辑草稿不混入持久化文档。
- 可兼容字段使用可选属性，旧值有明确默认解释；需要改变元素种类或既有几何含义时显式评估 schema version 和迁移。每次导入仍完整校验再替换场景。
- 第一阶段图片使用 PNG/JPEG/WebP/GIF raster data URL，原始文件不被改写；超出内嵌限制的静态图进行有界缩放/编码并告知，无法安全转换的输入给出错误。保持单元素和文档大小限制，批量输入原子提交；解码期间切换文档或修改文档时丢弃旧结果，释放创建的资源。
- 新建文件使用独立的 create-only 操作：只接受 allowed roots 内的现有父目录，校验 basename 和 `.whiteboard` 内容，已有目标返回冲突。不能通过新接口绕过既有 revision 保存逻辑，也不自动建立目录或扩大 allowed roots。
- 文件选择复用已有 workspace roots 与文件列表 API；加载结果按请求版本发布。新白板另存成功后沿用源文件的 canonical filepath/revision 和相应草稿 key。
- 扩展连线后，renderer、命中测试、边界、绑定和控制点共享 pure geometry；旋转以节点中心为锚点，连接锚点保留局部坐标。调整尺寸与内容排版的交互须给出一致规则后实现。
- 锁定阻止几何、内容和样式编辑；允许显式解锁与隐藏/显示。复制和导出不会隐式把锁定对象改为可编辑对象。隐藏元素不参与可见命中与适配内容。
- 任意排序以文档元素列表为唯一顺序。阅读视图按可见 SVG 绘图与 DOM 卡片交错合成，概览保留相同顺序；避免按卡片数量分配全屏 Canvas。旧文件缺少 stacking 标记时先按原三层稳定排序，再标记 stacking:document；显式标记后元素数组是唯一顺序。现有三层限制在此阶段正式替换。
- 导出复用场景几何与主题解析；Markdown 内容、图片和字体须在生成前就绪。优先 SVG + 嵌入资源路径，PNG 使用浏览器原生 rasterization；不以缺失富内容的图片冒充完整导出。
- 命名区域是持久化空间边界，演示步骤引用区域；阅读模式、激光尾迹和当前步骤属于临时会话状态。命名区域不隐式改变元素的所属或 z-order。
- AI 在外部系统运行，白板提供环境无关的批量命令 core、文档 JSON schema 与 Node 24 CLI。命令先完整校验再提交，返回结构化诊断和结果；CLI 文件修改保持 revision 检查和安全写入。
- 打开的 `.whiteboard` 文件订阅或轮询外部更新：无本地改动时自动刷新；有本地改动或活跃手势/编辑草稿时保留用户状态并提示磁盘版本，不静默覆盖。多人协作与内置 AI provider 明确不属于本 goal。
- 不新增第三方依赖；确需依赖时先完成候选评估并取得授权。不访问 secret 文件，不自动 commit/push。

### 文字尺寸契约

- 普通文字、图形/连线标签支持 hand/sans/mono、8–200 字号、normal/bold、left/center/right；旧文档使用原默认值。Markdown 排版仍由其正文控制。
- text/shape 可设 autoSize；浏览器按实际字体测量后更新宽高，固定左上角，修改与尺寸变化同一历史。手动拉伸或 agent 显式修改宽高时退出自动尺寸，除非 agent 同时指定 autoSize:true。
- 自动尺寸的序列化宽高是布局提示，浏览器载入时重新计算；CLI 不加载浏览器字体，布局命令使用文件内的宽高。需要精确固定几何时使用 autoSize:false 并指定尺寸。
- 自动尺寸按最长段落测量，正文换行宽度最多 800，测量高度最多 10000；固定框保留已有尺寸，预览单行最多 8192、最多 2000 行，超出范围显示省略号且保留原文。

### 旋转与翻转契约

- 节点使用可选 rotation（角度）、flipX/flipY；局部镜像后绕节点中心旋转。内容随节点变换，连线标签保持水平可读；编辑器仍保持正向。
- 选区旋转/世界轴翻转保持节点相对布局，选中的自由端点与控制点同步变换；自动路线在变换时生成显式控制点，外部绑定不脱离。只有一个绑定端点的单条连线以绑定端点为轴。
- 单节点尺寸手柄沿局部坐标轴，固定对角；非直角旋转的多选保持比例，直角旋转的多选可精确按世界轴拉伸。旋转中的外框跟随手势，结束后多选重新使用轴对齐包围盒。
- 自动尺寸保持经过旋转/镜像后的局部原点；不改变文本、分组或元素 ID。手柄整次拖动一次历史，Esc 取消，Shift 15° 吸附。
