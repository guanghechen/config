# Whiteboard v1

## 产品目标与已确认范围

提供用于零碎思考、技术讲解和本地屏幕分享的自由画布。UI 借鉴 Excalidraw，自己实现场景模型、手绘图形、交互、历史与渲染调度，复用已有 Markdown、Monaco 和文件 API，不新增依赖。

- 节点和连线组成一般图，不要求树结构、单一根或强类型 port。
- 支持自由绘制、选择、移动、调整尺寸、缩放与平移。
- Markdown 是一等节点：内嵌内容与实时引用外部 `.md` 均支持。
- Markdown 原地展开 Monaco 编辑，完整支持项目现有公式、代码、表格、Mermaid、图片与链接渲染。
- 引用编辑保存时写回源文件，并检测外部修改冲突，冲突时保留草稿。
- 1000 个节点的场景仍应能流畅拖拽、缩放和编辑。
- 不内置 AI provider；外部 agent 通过文件、schema 和批量命令驱动画布。
- 本地屏幕分享无需发布页面或多人协作；命名区域可用于演示编排。

本文件替代已删除的旧设计；旧 port、WebGL、floating window、registry 和目录约定均不沿用。

## 首版交付

页面入口为 `/whiteboard`，提供独立工作区。已有 workspace/file 查看器可通过 `.whiteboard` 文件进入白板。

- 顶部工具栏：选择、抓手、矩形、椭圆、菱形、连线、自由笔、文字、Markdown、图片。
- 左侧属性面板：描边、填充、线宽、手绘程度；单选、多选与删除。
- 选择与编辑：框选、Shift 多选、移动、尺寸手柄、复制、粘贴、重复、undo/redo。
- 连线端点可悬空或绑定节点边界；节点移动和尺寸变化后重新计算连接位置。
- Markdown 双击或 Enter 进入编辑；编辑区域位于节点位置，可以临时扩大，不改变持久化尺寸。Ctrl/Cmd+Enter 保存，取消保留已保存内容。
- Markdown 调整宽度会重新排版；调整高度改变可见区域，正文支持滚动。缩放画布不改变正文排版宽度。
- 文件引用节点显示源文件路径、加载状态与失败原因。外部修改更新预览；编辑中的草稿不被外部事件覆盖。
- 白板自动保存到浏览器草稿，可导入/导出 `.whiteboard`；已打开的服务端文件通过显式保存写回，并检测版本冲突。
- 画布提供缩放百分比、适配内容、聚焦选区及快捷键提示。

### 图编辑补齐

- 图片支持 I/工具栏选择、文件菜单、剪贴板和拖入；PNG/JPEG/WebP/GIF 嵌入文档，批量输入形成一次历史。单文件最多 20 MB、解码最多 40 megapixels，嵌入 URL 保持 2 MB 上限；过大的静态图优化为有界 WebP 并提示，动画图不静默扁平化。保留透明背景，初始显示最长 800×600，失败或过期输入不插入部分内容。
- Ctrl/Cmd+X 剪切选区；剪切与粘贴遵循编辑器/指针手势隔离，撤销恢复整次操作。
- 文件菜单支持另存为 workspace 内的新 `.whiteboard`；已有目标不会覆盖，成功后打开新文件继续编辑。源文件保存仍使用 revision 冲突检测。Markdown 引用提供 workspace 与目录浏览、文件搜索和绝对路径输入。

- 矩形、椭圆、菱形支持内置文字；连线支持居中标签。双击或 Enter 打开原地文本框，Enter 保存、Shift+Enter 换行、Esc 取消。
- 文字属于图形/连线自身，随移动、拉伸、复制和重连更新；单次保存形成一条历史，不创建独立文字节点。
- 单选连线显示两个端点手柄。拖到节点上重新绑定，拖到空白处转成自由端点；整次拖拽只产生一条历史，Esc 撤销预览。
- `shape.label`、`edge.label` 为可选字符串，最多 4000 字符；保持 schemaVersion 1，既有无标签文档仍可读取。空间不足时仅裁剪显示，原始文字完整保存。

### 锁定、隐藏与对象操作

- 属性面板或 Elements 列表可锁定/隐藏整组。Ctrl/Cmd+Shift+L 切换锁定；锁定阻止移动、尺寸、旋转、样式、内容、顺序与删除，显式解锁后恢复。复制保留 flags。
- 锁定连线会阻止节点的连带删除，仍按已有绑定跟随未锁定节点移动。隐藏节点同时隐藏 incident edges；从列表恢复节点后，原本未独立隐藏的连线重新显示。
- Elements 按前后顺序展示，支持内容、ID、类型搜索与虚拟列表；单击选择、Shift-click 扩展组、双击聚焦。隐藏/锁定对象可从列表找回；隐藏节点不参与画布命中、全选、适配内容与吸附目标。
- Ctrl/Cmd+click 轮换重叠可编辑对象；右键提供复制、剪切、指定位置粘贴、重复、编辑、分组、顺序、锁定、隐藏和删除，以及命中对象列表。异步剪贴板检查文档、选区及活跃手势，过期结果不删除错误对象或合并进新手势。
- E 切换橡皮擦；单击删除最上方一个可删除对象，拖动沿路径擦除；删除扩展整组和依赖连线，锁定前景不被穿透。组内隐藏成员随组操作保持一致。每次手势一条历史，Esc 取消预览，undo 恢复整次擦除。

### 文字样式与自动尺寸

- 普通文字、图形标签和连线标签支持 hand/sans/mono 字体、8–200 字号、normal/bold 和 left/center/right 对齐。未设置时，普通文字沿用 24px 手写字体与左对齐，标签沿用 20px 等宽字体与居中。
- 新文字节点默认 autoSize；已有文字与图形保持固定尺寸，用户可显式开启。内容或文字样式变化时按当前浏览器字体重算宽高，固定经过变换后的局部原点，绑定连线随边界更新；内容和尺寸一起提交与撤销。
- 手动拉伸会关闭所选 text/shape 的 autoSize；单击尺寸手柄或移动节点不会关闭。自动尺寸的正文换行宽度最多 800，测量高度最多 10000；固定框预览最多 8192 宽、2000 行，超出显示省略号且保留完整原文。
- 原生字体测量用于绘制、自动尺寸与标签命中；按节点内容、字体和排版尺寸缓存，平移/缩放不重新测量文本。英文优先按词换行，长单词及中文按 grapheme 边界拆分，保留组合字符和 emoji。
- autoSize 节点的序列化宽高是布局提示，载入时按当前浏览器字体重算；保存记录当前实际尺寸。CLI 使用文件内的几何，精确固定布局可使用 autoSize:false。修改宽高的 agent update 默认关闭 autoSize，显式 autoSize:true 可保留自动模式。

### 连线路线与样式

- 连线支持 straight、polyline、curve；旧文档缺省仍为直线单向箭头。起点和终点可独立设置 none/arrow，线身支持 solid/dashed/dotted，箭头始终使用完整笔迹。
- 单选连线时，圆形手柄重连端点，方形手柄编辑路线。折线最多 64 个控制点，可增加最长线段的中点、删除末尾折点或 Alt-click 删除指定折点；曲线使用两个 cubic Bézier 控制点。Reset route controls 恢复自动路线。
- `edge.routing`、`controls`、`arrowStart`、`arrowEnd`、`lineStyle` 为 v1 可选字段。controls 缺省时由端点生成；显式控制点是世界坐标，随选中的连线移动、复制、布局和拉伸。未选中的连线控制点不随节点隐式移动，绑定端点继续跟随节点。
- 折线标签位于路线长度中点，曲线标签位于 t=0.5；渲染、命中与选择边界共享路线几何。切换路线会重建控制点；整次控制点拖动形成一条历史，Esc 取消。
- 属性面板设置会用于下一条新连线；agent 的 update 改 routing 时同样清除旧控制点，除非该 patch 显式提供 controls。

### 手绘风格

- 图形使用带轻微弯曲和错位的双笔迹轮廓，椭圆使用平滑曲线；连线与箭头采用相同的手绘笔触。提供 Clean、Subtle、Sketch、Rough 四档，新元素默认 Sketch（roughness 2）；已有元素保留其数值。
- 形状支持实色、斜线和交叉斜线填充。`style.fillPattern` 为可选的 `solid | hachure | cross-hatch`，缺省按实色处理；schemaVersion 1 不变。填充使用所选填充色，透明色仍表示不填充。
- Markdown 与图片卡片共享手绘轮廓，正文保留清晰排版与滚动，不在正文上叠加斜线。自由笔用平滑曲线连接采样点，不添加随机抖动。
- 手绘几何仅由元素 ID、尺寸、形状和样式确定。平移和镜头变化不改变笔迹；撤销、恢复和导入后呈现相同笔迹。命中测试仍按逻辑几何进行。
- SVG、Canvas 和卡片边框共享本地路径生成器，不引入 Rough.js 或 Excalidraw。概览省略密集斜线并以实色表达填充，避免远景细线噪声与重复绘制。
- 阅读视图使用 SVG 矢量笔迹、斜线和文字，未变更元素保持 DOM；概览沿用路径缓存与有界位图。

### 绘图辅助

- 工具栏、文件入口和镜头/历史控件使用同一套本地 SVG 图标；工具下方显示对应快捷键提示，继续继承站点主题，不引入图标依赖。
- 工具栏锁定按钮或 Q 切换连续绘图。默认画完一个元素后回到选择工具；锁定后保持当前工具，自由笔继续保持原有连续绘制行为。Esc 取消当前手势并回到选择工具。
- 绘制矩形、椭圆、菱形时，Shift 约束等宽高，Alt 以起点为中心，二者可组合。按下或松开修饰键会立即更新预览；单击创建默认尺寸时也遵循这些约束。
- Shift 将新连线约束为 45° 的整数倍，以实际源端点为锚点；受约束的目标端点保持自由坐标，避免绑定节点边界后破坏角度。不按 Shift 时沿用节点绑定行为。
- 移动节点、多选或分组时，以选区包围盒的边缘与中心吸附到邻近节点，并显示临时对齐参考线。阈值为 6 个屏幕像素，随缩放换算；Alt 临时关闭吸附，松开后恢复。
- 吸附候选在手势开始时建立，不包含选区成员、连线和自由笔；距离较远的无关行列不参与。所有成员共享同一位移，连接继续跟随节点；辅助线不写入文档，取消与撤销仍以整次手势为单位。

### 站点主题

- 白板继承 site 的 Light / Dark / Follow device 和当前 palette，覆盖 VS Code Light / Dark Modern、Rosé Pine Dawn / Moon / 主色板；不保存独立的白板主题偏好。页面复用站点 ThemeToggle 和 Settings。
- 界面颜色来自站点语义变量：画布/纸张、面板、输入框、文字、网格、选区、焦点、提示和错误状态共享站点配色。Markdown、公式、代码与 Monaco 跟随同一主题。
- 元素颜色支持 `theme:ink`、`theme:paper`、`theme:accent`、`theme:red`、`theme:amber`、`theme:green`、`theme:blue`、`theme:purple`。新元素默认使用主题笔迹和纸张；彩色实心填充采用淡色背景，斜线使用对应笔迹色，语义笔迹保持可读对比度。
- 笔迹和图形填充的十六进制颜色与 transparent 保持原意，旧文档不会自动改写。属性面板提供主题色 swatches，旧元素可通过选区显式改用主题色；自定义颜色仍由 color input 指定。Markdown/图片卡片的正文纸张由站点主题控制，阅读与概览一致。
- 主题只影响显示；切换不会更改文档、创建历史或丢失编辑草稿。Canvas 在 palette 更新后重绘，解析颜色缓存和概览位图同步失效，形状位图按实际颜色更新。读取 CSS 变量只发生在主题更新时。
- `schemaVersion: 1` 不变，颜色解析接受上述明确列出的语义值，拒绝未知主题 token。

### 分组与布局

- 选区可分组（Ctrl/Cmd+G）或取消分组（Ctrl/Cmd+Shift+G）。使用元素可选的非空 `groupId`（最多 128 字符），保持 schemaVersion 1；旧文档无需迁移。
- 首版为扁平分组，再次分组会将选中组与其他选中元素合成一个组；只纳入显式选中的元素，不自动吸收连线。点击、Shift 切换和框选任一成员均作用于整组。
- 组支持整体移动、样式修改、删除、复制与粘贴；副本重建 group ID 和内部连线引用，与原组独立。双击仍可编辑成员内容；单独调整成员位置或尺寸前先取消分组。
- 属性面板提供左/水平居中/右、上/垂直居中/下对齐，以及水平/垂直等间距分布。至少两个布局单元可对齐，至少三个可分布；一个组算一个单元，组内相对位置保持不变。
- 布局边界由节点决定；连线自身不参与边界计算。组内连线的自由端点随组平移，绑定端点继续跟随目标节点；只含连线的组不参与对齐或分布。
- 分布按对应轴起点排序，固定首尾单元，以边界间距均分中间单元；空间不足时允许负间距（重叠）。每次分组、取消分组、对齐或分布各形成一条可撤销历史。

### 选区变换

- 单个节点、多选和分组均提供统一的四角尺寸手柄；固定对角，拖动改变选区内节点的位置与尺寸，Shift 保持整个选区的宽高比。单独调整组内成员仍需先取消分组。
- 尺寸手柄的边界包含选中节点与选中连线的自由端点，排除文字标签和绑定在组外的端点。纯连线选区不显示整体尺寸手柄，单选连线仍使用端点重连手柄。
- 所有选中节点使用同一缩放比例；自由端点随选区变换，绑定端点保持相对锚点并跟随目标节点。Markdown 按新尺寸排版，字号、描边宽度、内容与分组关系保持不变。
- 拖动不翻转选区；每个节点的宽高最低为 16 个世界坐标单位，原本小于 16 的尺寸以原值为下限，避免点击手柄就跳变。整轮拉伸为一次历史，Esc 取消预览。
- 方向键以 1 个世界坐标单位移动选区，Shift+方向键为 10 个单位，不随镜头缩放改变。连续按住方向键（含重复事件与组合方向）形成一次历史，全部方向键松开时提交；Esc 取消本轮微调。
- 输入框与原地编辑器保留方向键原有行为。切换焦点、开始鼠标操作或执行其他白板命令前提交微调，避免与下一次操作混成同一历史。

### 旋转与翻转

- 选区上方的圆形手柄用于旋转，Shift 吸附到 15°；属性面板提供角度、±90° 和水平/垂直翻转。单节点角度为绝对值，多选为相对增量。
- 节点 rotation 以角度记录，flipX/flipY 在局部坐标中先镜像，再绕节点中心旋转；文字、图片、Markdown 内容与节点一起变换，编辑器保持正向。连线标签保持水平。
- 多选/分组按选区中心旋转或世界轴翻转，保留成员相对位置与方向；选中的自由端点和控制点同步变换，自动路线生成显式控制点，外部绑定继续保持。单条一端绑定的连线以绑定端点为轴；两端绑定的直线不能独立旋转。
- 单节点拉伸沿局部坐标轴固定对角；非直角旋转的多选自动保持比例，直角旋转的多选可按世界轴独立拉伸。绘制、命中、可见性裁剪、对齐/吸附和适配内容使用同一变换几何。
- 整次旋转手势、角度输入或翻转形成一条可撤销历史，Esc 取消旋转预览；保存、恢复、复制及 agent 命令保留姿态。

### 图层顺序

- 属性面板提供置底、后移、前移、置顶；Ctrl/Cmd + `[` / `]` 后移/前移，加 Shift 置底/置顶。到达边界时禁用对应按钮；无变化的操作不创建历史，也不清空 redo。
- 所有元素类型共享一个前后顺序；文档元素数组从后向前排列，阅读与概览保持一致。
- 多选与分组保留成员的相对顺序。置顶/置底移动到整个场景的端部；前移/后移让每段连续选中成员越过一个相邻未选中元素。选中组内任一成员时整组参与，不自动纳入组外连线。
- 重排只改变元素数组顺序，保留元素 ID、内容、几何和连接关系；命中测试、草稿、文件保存与导入导出沿用同一顺序，schemaVersion 1 不变。每次操作形成一条可撤销历史。新文件标记 stacking:document；没有标记的旧文件先按原三层稳定排序，保留旧视觉后写入标记。
- 文本输入和原地编辑器保留括号快捷键；指针手势期间不执行重排，键盘微调先提交再重排，两次操作可分别撤销。

### 图片导出

- 文件菜单支持全板或选区 PNG/SVG 导出，以及复制 PNG；PNG 可选 1×/2×/4×，可保留或移除画布背景。隐藏内容不导出，锁定内容仍可导出；节点姿态、图层顺序、连线和文字保留。
- Markdown、公式、代码、表格、Mermaid、引用文件及图片按卡片的保存尺寸渲染。引用内容在导出开始时冻结，每批最多额外挂载 16 个元素；等待资源和内嵌字体解码后再生成图片。资源或渲染失败会显示可定位的错误，取消后清理临时内容与请求。
- SVG 保留矢量绘图，并嵌入图片、可访问的 Web 字体及富内容 HTML。富内容使用 SVG foreignObject，浏览器可完整显示；不支持 foreignObject 的图片工具应使用 PNG。系统字体仍由查看设备提供。
- PNG 上限 32 megapixels、单边 16384 像素；超限可降低倍率、缩小选区或改用 SVG。导出资源累计最多 60 MB、最终 SVG 最多 100 MB；不静默丢弃超限内容。主题在生成期间变化会要求重新导出，避免混合配色。

### 导航与演示

- Elements 搜索元素内容、ID、类型及引用 Markdown 的正文，包括画面外的卡片。引用读取最多四路并发；结果加载中或部分文件不可读时显示状态，清空搜索/关闭列表会取消不再使用的读取。
- Minimap 显示节点、连线、命名区域与当前视口；点击或拖动导航，双击适配内容，也支持方向键与 Enter。镜头变化不写入文档，不创建历史。
- Navigate 面板可从选区或当前视口建立命名区域，支持重命名、聚焦、删除；区域是导航边界，不改变元素的分组、顺序或图片导出内容。区域与演示步骤保存在 `.whiteboard`，详情见 agent 契约。
- 步骤可重复引用区域并上下排序。Present 进入演示，方向键、PageUp/PageDown、Space、Home/End 切换步骤，Esc 退出并恢复先前镜头与工具；演示时隐藏编辑控件。
- 图片与 Mermaid 全屏预览隔离白板手势和快捷键；Esc 先关闭预览，图库方向键只切换图片。预览支持焦点循环和关闭后恢复焦点，打开期间延后应用源文件更新。
- 阅读模式保留平移、缩放、卡片链接/滚动、搜索和复制，禁用文档编辑与 undo/redo。已有编辑草稿打开时，阅读/演示入口禁用；异步图片和剪贴板操作也检查模式变化。
- L 激光指针按住拖动显示红色轨迹，约 0.9 秒消退，不改变场景。双指触摸可同时平移和缩放；第二指加入会取消未提交的绘图，抬起一指后剩余手指继续平移，全部松开后恢复原工具。

## 模块与状态边界

- `src/view/whiteboard/`：页面、私有场景模型、交互、Canvas renderer、节点、工具栏与文档生命周期。
- `shared/whiteboard/`：环境无关的文档类型、解析校验与几何函数；供 Node 测试与浏览器复用。
- `src/container/markdown/`：复用现有 Markdown renderer；原地编辑器使用已安装的 Monaco 与 `@monaco-editor/react`，留在 whiteboard 模块内。
- `server/`：沿用现有鉴权及 allowed roots，提供带版本的文本读取与条件保存。
- 场景文档只有一个 owner；选择、镜头、拖拽预览、编辑草稿、资源缓存不混入持久化文档。
- 文档编辑统一通过事务提交。一轮拖拽、一次粘贴或一次内容保存各形成一条历史。取消交互恢复原值。
- 外部文件内容属于源文件，不随白板的布局 undo 回滚；引用文件的编辑草稿与 Monaco 文本撤销独立。
- 异步资源结果按请求版本发布，过期结果忽略；订阅、timer、DOM 和 object URL 有对应清理。

## 数据契约

- `.whiteboard` 是 JSON：固定 `kind: "yoz.whiteboard"`、`schemaVersion: 1`、文档 ID、标题、元素列表。
- 元素种类为 shape、stroke、text、markdown、image、edge。节点具有 ID、位置、尺寸、样式；元素列表顺序定义同层绘制顺序。
- 连线保存两个端点；端点是世界坐标，或节点 ID 加相对边界锚点。连线置于节点下方，交互反馈置于全部内容上方。
- Markdown source 是内嵌文本或文件引用的 discriminated union。文件引用保存路径，不复制源文件正文到权威文档。
- ID 使用浏览器 `crypto.randomUUID()`，不引入 ID dependency。
- 导入先验证版本、唯一 ID、有限坐标、尺寸、引用与元素字段，失败不替换当前场景。
- 本地草稿使用独立带版本的 key；草稿写入失败保留当前内存内容并展示错误，不显示已保存。

## 渲染与性能

阅读视图将 SVG 绘图与 DOM 富内容卡片按文档顺序交错排列；概览使用 Canvas 2D，同样按文档顺序绘制。交互反馈使用独立 Canvas；编辑器使用 DOM。

- 使用 `requestAnimationFrame` 合并绘制请求；空闲时不持续绘制。
- 镜头和拖拽更新不重新解析所有 Markdown。相同路径的引用共享加载与内容缓存。
- 工具栏、样式控件和底部导航独立 memo 渲染；拖动和拉伸期间不重建与几何无关的控件，避免每帧重复生成整页 JSX。
- 绘图与卡片均只挂载视口附近内容；概览 Canvas 同样裁剪视口。远景采用标题/概要预览，恢复可读尺寸时显示完整内容。
- Monaco 仅为当前编辑节点挂载；编辑器维持可读屏幕尺寸，不随远景镜头缩成不可用控件。
- Monaco 文本模型持有编辑草稿，保存时直接读取模型；不把每次输入经 React value 再写回模型。
- 概览复用带 overscan 的 Canvas 位图，通过 CSS transform 移动和缩放；镜头停止后重新按实际比例绘制。阅读视图复用未改变的 SVG/DOM 节点，不按卡片边界分配全屏 Canvas。
- 网格保持 16–32 屏幕像素的点距；没有选择和框选时隐藏交互 Canvas，避免无效清屏与合成。
- 手绘路径使用稳定种子；移动不重新随机化笔迹。按几何与样式缓存路径。
- 命中测试先使用包围盒，再做几何判定；所有坐标转换集中在 pure geometry 模块。
- 先通过 profiling 验证瓶颈，再决定是否增加空间索引、worker 或 WebGL。

固定性能样本：1000 个节点（形状、文字、内嵌 Markdown、公式、代码、表格、Mermaid 混合）及 1000 条连线。分别验证局部阅读与全图概览，不能只用空矩形代替富内容。

验收记录设备、Chromium 版本、分辨率及运行模式。1080p、60Hz 目标：稳定交互平均 >=55 FPS，P95 帧间隔 <=33.4ms；报告 pan、zoom、拖拽各自结果。首次渲染与资源加载单独记录，不算作已验证的稳定交互性能。软件渲染测试结果须注明环境限制。

## 文件读写与冲突

- 新文本读取契约返回 canonical filepath、content、revision；revision 由实际内容计算。
- 保存携带读取时的 expected revision。版本不符返回 409，保留编辑草稿，并提供查看磁盘版本、重新加载和复制草稿的路径。
- 服务端同一路径的本应用保存串行执行，避免两个本应用请求同时通过校验。
- 保存使用同目录临时文件，保留原权限，并在替换源文件前再次检查 revision。写入失败不会先截断源文件。
- 外部编辑器不受本应用锁控制；保存前重新读取校验，文档不得将此描述成跨进程的绝对原子 compare-and-swap。
- 引用预览订阅文件变更，并在重新聚焦页面时补偿刷新。每 2.5 秒轮询补偿缺失事件，最多 4 个并发请求；同一引用路径共享请求，响应的 canonical filepath 用于写回和事件匹配。显式文件更新会取消过期请求。
- Markdown 相对资源以源文件目录解析；内嵌 Markdown 可使用绝对工作区文件路径或 HTTP(S) URL。
- 文件 API 必须保持现有鉴权、allowed roots 与路径校验；新增能力不扩大访问范围。
