# Windows FAQ

## Input Method

1. Enable `Caps Lock` to toggle the `Chinese` and `English` Input Method

   - Open the PowerToys -> Keyboard Manager -> Remap Keys -> Add key remapping
   - Left choose `Caps Lock`, Right Choose the `Win+Space` (You can click the `Select` button then just pressed the `Win+Space` to quick insert the form)

2. (Optional) Better to disabled the `Shift` key to toggle the Input Mode (Pinyin/English) for the Chinese Input Method.
   - Settings -> Time & language -> Language & region -> Chinese ... Language Options -> Keyboards -> Microsoft Pinyin ... Keyboard Options -> Keys

3. (Optional) Settings -> Time & language -> Typing -> Advanced keyboard settings
   - Default choose the Chinese Input Method
   - uncheck the `Let me use a different input method for each app window`
