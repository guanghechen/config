# 🤖 AI Agent: Your Intelligent Markdown Assistant

Welcome to AI Agent, your smart companion for markdown editing and preview! This tool combines the
power of artificial intelligence with a clean, intuitive interface to enhance your markdown writing
experience.

## ✨ Key Features

- **Smart Preview**: Real-time markdown rendering ^[wulala balabala]
- **Theme Toggle**: 🌞 Light and 🌙 Dark modes for comfortable viewing
- **File Management**: Easy file loading and navigation
- **Intelligent Assistance**: AI-powered suggestions and formatting

## 🚀 Getting Started

1. Use the file selector at the top to open your markdown files
2. Write or edit your markdown content
3. See instant preview of your changes
4. Toggle between light and dark themes using the sun/moon switch
5. Save your changes automatically

## 📝 Markdown Support

This previewer supports all standard markdown syntax:

### Text Formatting

- **Bold** (`**text**`)
- _Italic_ (`*text*`)
- ~~Strikethrough~~ (`~~text~~`)

### Lists

- Bulleted lists
- Numbered lists
- Task lists
  - [x] Completed task
  - [ ] Pending task

### Code

```javascript
console.log("Hello, World!");
```
