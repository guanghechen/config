# 人工智能领域常见损失函数（中英对照）

---

## 一、回归任务（Regression）

| 英文名称                          | 中文名称               | 公式简述                          | 特点                             | 适用场景                 |
|-----------------------------------|------------------------|-----------------------------------|----------------------------------|--------------------------|
| MSE (Mean Squared Error)          | 均方误差               | $\frac{1}{n}\sum(y-\hat{y})^2$    | 对大误差敏感，处处可导           | 通用回归                 |
| MAE (Mean Absolute Error)         | 平均绝对误差           | $\frac{1}{n}\sum\|y-\hat{y}\|$    | 对 outlier 鲁棒，零点不可导      | 含噪声数据               |
| Huber Loss                        | Huber 损失             | MSE/MAE 分段组合                  | 兼顾 MSE 平滑和 MAE 鲁棒性      | 鲁棒回归                 |
| Log-Cosh Loss                     | 对数双曲余弦损失       | $\sum\log(\cosh(\hat{y}-y))$      | 类似 Huber，二阶可微             | 需要平滑梯度的回归       |
| Quantile Loss                     | 分位数损失             | 分位数加权的绝对误差              | 可预测不同分位数                 | 区间预测、不确定性估计   |
| MAPE (Mean Absolute % Error)      | 平均绝对百分比误差     | 百分比误差的均值                  | 无量纲，直观                     | 业务指标预测             |
| MSLE (Mean Squared Log Error)     | 均方对数误差           | 对数空间的 MSE                    | 关注相对误差而非绝对误差         | 目标值跨数量级（如房价） |

## 二、分类任务（Classification）

| 英文名称                            | 中文名称                 | 适用类型     | 特点                                     | 适用场景                   |
|-------------------------------------|--------------------------|--------------|------------------------------------------|----------------------------|
| Binary Cross-Entropy (BCE)          | 二元交叉熵               | 二分类       | 基于信息论，概率输出                     | 逻辑回归、二分类网络       |
| Categorical Cross-Entropy           | 分类交叉熵               | 多分类       | 配合 softmax，标准多分类损失             | 图像分类、NLP 分类         |
| Sparse Categorical Cross-Entropy    | 稀疏分类交叉熵           | 多分类       | 标签为整数而非 one-hot                   | 类别数量很多时             |
| Hinge Loss                          | 合页损失 / 铰链损失      | 二分类       | 最大间隔思想                             | SVM                        |
| Squared Hinge Loss                  | 平方合页损失             | 二分类       | Hinge 的平方版，处处可导                 | SVM 变体                   |
| Multi-class Hinge                   | 多分类合页损失           | 多分类       | Hinge 的多分类推广                       | 多分类 SVM                 |
| Focal Loss                          | 焦点损失 / 聚焦损失      | 二/多分类    | 下调 easy sample 权重，聚焦 hard sample  | 类别极度不平衡（目标检测） |
| Label Smoothing Cross-Entropy       | 标签平滑交叉熵           | 多分类       | 软化标签防过拟合                         | 大规模分类                 |
| KL Divergence                       | KL 散度 / 相对熵         | 分布匹配     | 衡量两个概率分布的差异                   | 知识蒸馏、VAE              |

## 三、排序/度量学习（Ranking / Metric Learning）

| 英文名称               | 中文名称                 | 特点                             | 适用场景                   |
|------------------------|--------------------------|----------------------------------|----------------------------|
| Triplet Loss           | 三元组损失               | 拉近正对、推远负对               | 人脸识别（FaceNet）        |
| Contrastive Loss       | 对比损失                 | 成对样本的距离约束               | Siamese Network、自监督    |
| InfoNCE / NT-Xent      | 信息噪声对比估计损失     | 对比学习的标准损失               | SimCLR、CLIP               |
| Margin Ranking Loss    | 间隔排序损失             | 排序对之间保持间隔               | 推荐系统、信息检索         |
| Circle Loss            | 圆形损失                 | 自适应调节正负样本对的权重       | 人脸识别、图像检索         |
| ArcFace Loss           | 弧面损失 / 角度间隔损失  | 角度间隔增强的 softmax           | 人脸验证                   |
| CosFace Loss           | 余弦间隔损失             | 余弦空间中添加间隔               | 人脸验证                   |

## 四、生成模型（Generative Models）

| 英文名称                       | 中文名称                   | 特点                                     | 适用场景               |
|--------------------------------|----------------------------|------------------------------------------|------------------------|
| Reconstruction Loss            | 重建损失                   | 重建输入与输出之间的差异                 | Autoencoder            |
| ELBO / VAE Loss                | 变分下界损失               | 重建损失 + KL 散度正则                   | VAE（变分自编码器）    |
| GAN Loss (Minimax)             | 生成对抗损失               | 生成器与判别器的对抗博弈                 | 原始 GAN               |
| Wasserstein Loss               | Wasserstein 距离损失       | 基于推土机距离                           | WGAN                   |
| Perceptual Loss                | 感知损失                   | 利用预训练网络的特征空间差异             | 超分辨率、风格迁移     |
| Diffusion Loss (Denoising)     | 扩散去噪损失               | 预测噪声的 MSE                           | DDPM、Stable Diffusion |

## 五、目标检测/分割（Detection / Segmentation）

| 英文名称          | 中文名称                          | 特点                           | 适用场景            |
|-------------------|-----------------------------------|--------------------------------|---------------------|
| IoU Loss          | 交并比损失                        | 直接优化交并比                 | 目标检测            |
| GIoU Loss         | 广义交并比损失                    | 解决不重叠框梯度为零的问题     | 目标检测            |
| DIoU Loss         | 距离交并比损失                    | 加入中心点距离约束             | 目标检测            |
| CIoU Loss         | 完全交并比损失                    | 加入中心距离和宽高比约束       | 目标检测（YOLOv5+） |
| Dice Loss         | Dice 损失 / 骰子系数损失          | 基于 Dice 系数                 | 医学图像分割        |
| Tversky Loss      | Tversky 损失                      | Dice 的推广，可调 FP/FN 权重   | 不平衡分割          |
| Lovász-Softmax    | Lovász-Softmax 损失               | IoU 的凸代理                   | 语义分割            |

## 六、序列/NLP 任务

| 英文名称                   | 中文名称                     | 特点                                 | 适用场景                |
|----------------------------|------------------------------|--------------------------------------|-------------------------|
| CTC Loss                   | 连接时序分类损失             | 无需对齐的序列损失                   | 语音识别（ASR）         |
| Sequence Cross-Entropy     | 序列交叉熵损失               | Token 级交叉熵求和/平均             | 机器翻译、语言模型      |
| RLHF (PPO Loss)            | 人类反馈强化学习损失         | 基于人类偏好的强化学习               | LLM 对齐                |
| DPO Loss                   | 直接偏好优化损失             | 无需奖励模型的偏好学习               | LLM 对齐（ChatGPT 等） |
| REINFORCE                  | 策略梯度损失                 | 基于奖励信号的策略梯度               | 文本生成、对话系统      |

## 七、正则化相关

| 英文名称               | 中文名称         | 特点                   | 适用场景                |
|------------------------|------------------|------------------------|-------------------------|
| L1 Regularization      | L1 正则化        | 稀疏化权重             | 特征选择（Lasso 回归）  |
| L2 Regularization      | L2 正则化        | 限制权重大小           | Ridge 回归、权重衰减    |
| Elastic Net            | 弹性网络正则化   | L1 + L2 组合           | 兼顾稀疏和稳定          |
| Center Loss            | 中心损失         | 类内紧凑               | 配合 softmax 联合训练   |

## 选择建议总结

| 任务类型               | 推荐首选                                     |
|------------------------|----------------------------------------------|
| 回归                   | MSE（通用）→ Huber（有 outlier）             |
| 二分类                 | Binary Cross-Entropy（二元交叉熵）           |
| 多分类                 | Categorical Cross-Entropy（分类交叉熵）      |
| 类别不平衡分类         | Focal Loss（焦点损失）+ 类别权重             |
| 人脸/图像检索          | ArcFace（弧面损失）/ Triplet Loss（三元组损失）|
| 对比学习/自监督        | InfoNCE（信息噪声对比估计损失）              |
| 目标检测 bbox 回归     | CIoU Loss（完全交并比损失）                  |
| 医学图像分割           | Dice Loss + Cross-Entropy                    |
| 文本生成/语言模型      | Cross-Entropy（交叉熵，token 级）            |
| LLM 对齐               | DPO（直接偏好优化损失）/ RLHF               |
| 图像生成               | GAN Loss / Diffusion Loss + Perceptual Loss  |

---

> **备注**：部分损失函数（如 Huber、Wasserstein、Dice、Tversky、Lovász）以人名命名，中文语境中通常直接保留英文原名，不做翻译。ArcFace / CosFace 等也是如此。上表中给出的中文名称为学术文献和教材中较常见的译法，但实际使用中**英文名称的使用频率往往更高**。
>
> 选择损失函数时的关键考量：**任务类型** → **数据特性**（噪声、不平衡）→ **优化属性**（可导性、梯度行为）→ **实际效果**（实验验证）。没有"最好"的损失函数，只有最适合特定任务和数据分布的损失函数。
