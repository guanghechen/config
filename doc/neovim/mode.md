# Neovim 模式详解

Neovim 有多种编辑模式，每种模式有不同的用途和触发方式。

## 基本模式

| 缩写  | 模式名称                          | 触发方式                                          | 说明                           |
|-------|-----------------------------------|---------------------------------------------------|--------------------------------|
| `n`   | 普通模式 (Normal)                 | 按 `<Esc>` 或 `<C-[>`                             | 默认模式，用于导航和执行命令   |
| `i`   | 插入模式 (Insert)                 | 按 `i`, `a`, `o`, `I`, `A`, `O` 等                | 用于输入文本                   |
| `v`   | 可视模式 (Visual)                 | 按 `v`                                            | 字符级别选择文本               |
| `V`   | 行可视模式 (Visual Line)          | 按 `V`                                            | 整行选择文本                   |
| `x`   | 块可视模式 (Visual Block)         | 按 `<C-v>` 或 `<C-q>`                             | 矩形块选择文本                 |
| `s`   | 选择模式 (Select)                 | 按 `gh`, `gH`, `g<C-h>` 或从可视模式按 `<C-g>`    | 类似可视模式，但输入会替换选区 |
| `o`   | 操作符待定模式 (Operator-pending) | 按操作符 (如 `d`, `c`, `y`) 后                    | 等待移动命令以完成操作         |
| `t`   | 终端模式 (Terminal)               | 在终端缓冲区输入时                                | 与内置终端交互                 |
| `c`   | 命令行模式 (Command-line)         | 按 `:`, `/`, `?`                                  | 输入 Ex 命令或搜索模式         |
| `!`   | 插入/命令行模式                   | -                                                 | 同时匹配 `i` 和 `c` 模式       |
| `l`   | Lang-Arg 模式                     | -                                                 | 用于语言映射的特殊模式         |

## 特殊模式组合

在定义键位映射时，可以使用模式组合：

| 组合        | 含义                                     |
|-------------|------------------------------------------|
| `""` (空)   | 匹配普通、可视、操作符待定模式 (n, v, o) |
| `"!"`       | 匹配插入和命令行模式 (i, c)              |
| `"nv"`      | 匹配普通和可视模式                       |
| `"nvx"`     | 匹配普通、可视和块可视模式               |
| `"invt"`    | 匹配插入、普通、可视和终端模式           |

```text collapsed=false
         ┌───────────────────────────┼───────────────────────────┐    │
         │                           │                           │    │
    i,a,o,I,A,O                      v                         :,/,?  │
         │                           │                           │    │
         ▼                           ▼                           ▼    │
   ┌───────────┐               ┌───────────┐               ┌────────────┐
   │  插入模式 │               │  可视模式 │               │ 命令行模式 │
   │    (i)    │               │    (v)    │               │    (c)     │
   └─────┬─────┘               └─────┬─────┘               └─────┬──────┘
         │                           │                           │
         └───────────────────────────┴───────────────────────────┘
                                     │
                                   <Esc>
                                     │
                                     ▼
                              返回普通模式
```
